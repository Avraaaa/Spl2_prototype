# P7-T15 orchestrator note
Root causes, found by running `mask_sensitive` over every corpus `sensitive_cases` entry (2026-11-24). All edits go in `services/api/domains/issues/services.py`, inside `mask_sensitive`.

1. **CARD_DIGITS runs before ACCOUNT/PHONE and has no Luhn check.**
   - `Phone +8801812345678` → `+[CARD REDACTED]`
   - `transfer to account 1234567890123` → `account [CARD REDACTED]`
   Fix: run PHONE and ACCOUNT before CARD, and require a Luhn-valid 13-19 digit run for CARD (4111 1111 1111 1111, 5500-0000-0000-0004, 4012888888881881 are valid; 1234567890123 is not).
2. **The Txn-reference sentinel holds a uuid hex nonce containing digits.** CARD_DIGITS matches inside it: `Txn ID 7788990011` → `⁣5d[CARD REDACTED]ae2f…⁣`. Use a sentinel with no ASCII or Bangla digits, e.g. a private-use character plus letters-only encoding of the index.
3. **OTP proximity masks the digits of reference codes.**
   - `E-1102` → `E-[OTP REDACTED]`
   - `SR-1043` → `SR-[OTP REDACTED]`
   OTP_DIGITS' lookbehind excludes only `\w`. It must also skip digit runs preceded by `<letters>-`, and runs that are part of `v2.4.1`, `12/11/2026` or `50,000`.
4. **Missed formats.**
   - Bangla-digit phones: `ফোন ০১৯১২৩৪৫৬৭৮`, `মোবাইল ০১৫১২৩৪৫৬৭৮`.
   - Account keywords: `acount 44012345678` (typo), `hisab 20012345678` (Banglish), `হিসাব নম্বর ৩২১০৯৮৭৬৫৪৩২` (Bangla digits).
