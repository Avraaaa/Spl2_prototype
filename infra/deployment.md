# Production hardening checklist — NOT a deploy recipe

`compose.prod.yaml` is an illustrative override, not a turnkey deployment. A banking client must approve: TLS reverse proxy (same-origin React+API), network segmentation, DB user with non-superuser privileges, RLS policy and tests, separate migration role, secret store, egress restrictions, AV attachment scanning, object-store encryption, mail relay, immutable backups and verified restore drill, audit chain anchors stored under a separate principal, alerting, retention/deletion policy, dependency SBOM, penetration test, disaster recovery, security ownership, rollback and patch procedure. Build immutable tagged OCI images; pin by digest and lock dependencies. Configure allowed hosts and CSRF origin explicitly. Never expose PostgreSQL or the NLP service externally.
